# Galaxy Voice to Codex

갤럭시 스마트폰을 무선 음성 입력기로 사용해 Windows PC의 VS Code Codex 입력창에 음성 변환 텍스트를 붙여넣는 로컬 도구입니다.

## 중요한 동작 원칙

- 같은 Wi‑Fi에 연결된 갤럭시와 Windows PC 사이에서만 사용하는 것을 권장합니다.
- 텍스트를 전송해도 Enter를 누르지 않습니다.
- Codex 명령을 자동 실행하지 않습니다.
- 기존 입력을 삭제하지 않고 현재 커서 위치에 붙여넣습니다.
- VS Code 창이 앞에 있고 허용된 창 제목을 포함할 때만 입력합니다.

## 설치 및 실행

1. Windows에 Python 3.10 이상을 설치합니다.
2. 이 폴더의 `start.bat`를 실행합니다.
3. 처음 실행할 때 Windows 관리자 권한 확인 창이 표시됩니다. 방화벽 규칙을 추가하려면 허용하세요. 개인 네트워크의 TCP 8765 포트만 열립니다.
4. 첫 실행 시 의존성이 자동 설치됩니다.
5. 콘솔에 표시된 PIN과 PC 주소를 확인합니다.
5. 자동으로 열린 `galaxy-voice-to-codex-qr.png`를 갤럭시 카메라로 스캔합니다.
6. 별도 앱이나 휴대폰 설치 없이 브라우저가 열립니다.
7. PIN을 입력하고 연결합니다.

QR 이미지가 자동으로 열리지 않으면 프로젝트 폴더의 `galaxy-voice-to-codex-qr.png`를 직접 열어 스캔하세요.

예:

```text
http://192.168.0.15:8765
```

Windows 방화벽이 접근을 묻는 경우 사설 네트워크만 허용하세요. 갤럭시와 PC가 같은 Wi‑Fi에 있어야 합니다.

## 사용 순서

1. VS Code에서 Codex 입력창을 클릭합니다.
2. 갤럭시에서 `말하기`를 누릅니다.
3. 한국어로 말합니다.
4. `중지`를 누르고 인식 결과를 수정합니다.
5. `전송`을 누릅니다.
6. PC 입력창의 내용을 확인한 뒤 필요할 때 직접 Enter를 누릅니다.

## 음성 인식 제한

브라우저의 Web Speech API 지원 여부와 마이크 권한은 브라우저와 버전에 따라 다릅니다. 지원되지 않으면 웹페이지에 직접 입력하거나 삼성 키보드의 음성 입력으로 텍스트를 만든 뒤 전송하세요. HTTPS가 필요한 브라우저에서는 자체 인증서를 준비해 HTTPS 포트로 실행해야 합니다.

## 설정

`.env.example`을 `.env`로 복사해 PIN, 포트, 허용 창 제목을 바꿀 수 있습니다. `ALLOWED_WINDOW_TITLES`에는 `Visual Studio Code` 또는 사용하는 VS Code 창 제목 일부를 입력합니다.

## 테스트

프로젝트 상위 폴더에서 다음 명령을 실행합니다.

```powershell
python -m unittest discover -s galaxy_voice_codex\tests
node --check galaxy_voice_codex\static\app.js
```

실제 클립보드 붙여넣기는 Windows에서 VS Code를 실행한 뒤 수동으로 확인해야 합니다.

## 보안

이 프로그램은 외부 인터넷에 공개하는 서버가 아닙니다. 라우터 포트 포워딩을 사용하지 마세요. 공개 네트워크에서 사용해야 한다면 HTTPS, 강한 PIN, VPN 또는 별도 접근 제어를 구성하세요.
