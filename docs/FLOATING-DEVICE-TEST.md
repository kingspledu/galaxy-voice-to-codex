# 플로팅 수집 실기기 검증

소스와 APK를 구현했지만 Galaxy에서 실제 실행한 결과는 아직 없습니다.

## 사용 순서

1. 앱에서 '플로팅 버튼 켜기 / 끄기'를 누릅니다.
2. 시스템 설정에서 '다른 앱 위에 표시'를 허용합니다. 돌아와 버튼을 다시 누릅니다.
3. 알림 권한 요청이 나오면 허용하는 것을 권장합니다. 거부해도 Android의 활성 앱 화면에 서비스가 표시될 수 있습니다.
4. YouTube에서 영상의 공유 메뉴로 앱에 링크를 전달합니다. 자동 제목·재생 위치 읽기는 하지 않습니다.
5. YouTube로 돌아가 화면 위 '메모' 버튼을 누릅니다. 길게 끌면 위치를 이동할 수 있습니다.
6. 작은 창에서 URL이 현재 영상과 일치하는지 확인하고 영상 시점을 입력합니다. 마지막 공유 영상은 계속 표시되므로 영상을 바꾸면 다시 공유하거나 URL을 수정하세요.
7. 녹음 시작 → 처음 한 번 마이크 허용 → 말하기 → 종료하고 저장을 누릅니다.
8. '녹음 저장 완료'를 확인하고 '닫고 영상으로 돌아가기'를 누릅니다.
9. 메인 앱에서 목록·재생·시점 링크를 확인합니다.
10. 플로팅 버튼은 앱의 토글 또는 플로팅 서비스 알림의 종료 버튼으로 끕니다.

## 검증 항목

- Android 13/14/15 이상인 Galaxy에서 각각 실제 권한 흐름과 서비스를 확인합니다.
- 플로팅 버튼 이동 후 앱 재실행·화면 회전 시 화면 밖으로 사라지지 않는지 확인합니다.
- 작은 창을 닫으면 YouTube 화면으로 복귀하는지 확인합니다.
- 녹음 중 홈/잠금/다른 앱 전환 시 알림이 유지되고 알림의 종료로 파일이 저장되는지 확인합니다.
- 녹음 중 메인 목록을 열어도 진행 상태가 중단됨으로 바뀌지 않는지 확인합니다.
- 메인 화면과 작은 창에서 동시에 녹음을 시작하지 못하는지 확인합니다.
- 준비 중 닫기·뒤로가기·화면 회전·알림 종료를 반복해 파일과 DB 상태를 확인합니다.
- 마이크/알림/오버레이 권한을 거부하거나 철회했을 때 충돌 없이 복구되는지 확인합니다.
- YouTube 음성이 마이크에 섞이는지 확인합니다. YouTube 재생을 강제로 일시정지하거나 영상 음성을 직접 녹음하는 기능은 없습니다.

## 구조와 제한

- `FloatingButtonService`: 사용자가 켠 표시 버튼을 유지하는 `specialUse` 포그라운드 서비스. 알림에서 종료할 수 있습니다.
- `CapturePopupActivity`: 별도 작업에 작은 창을 열고, 보이는 화면의 사용자 동작에서 마이크 서비스를 시작합니다.
- `RecordingService`: `microphone` 포그라운드 서비스. 음성 파일 및 Room 저장을 수행합니다. 자동 재시작하지 않습니다.
- 서비스 알림에서 녹음을 종료하면 메모 창은 다음 표시 때 상태를 갱신합니다.
- 강제 종료/배터리 제한/전원 차단 후에는 재생 불가능한 M4A가 남을 수 있습니다. 남은 파일은 삭제하지 않습니다.
- 오버레이의 `specialUse` 유형은 공개 Play 배포 시 별도 선언·심사 대상이 될 수 있습니다. 현재는 로컬 debug APK이며 Play 심사나 외부 배포를 하지 않았습니다.
- 내보내기 전 앱 데이터 삭제/앱 제거 시 녹음과 메모가 삭제됩니다.

참고: [포그라운드 서비스 시작 제한](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start), [서비스 유형](https://developer.android.com/develop/background-work/services/fgs/service-types).
