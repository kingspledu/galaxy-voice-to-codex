# 무료 전용 음성 변환

## 채택 방향

유료 음성인식 API, 기기 토큰, 중계 서버, 결제·유료 전환 기능을 사용하지 않습니다. 녹음 원본은 앱 내부에 보존하고 음성 변환은 Android 기기 안에서 실행합니다.

| 항목 | Transformers.js / Web Whisper | Android whisper.cpp |
| --- | --- | --- |
| 실행 환경 | 브라우저 JavaScript + ONNX Runtime, WebAssembly/WebGPU 경로 | Android ARM64 + NDK/JNI + CPU |
| 앱 연결 | WebView/브라우저와 파일 전달·모델 캐시 검증 필요 | 기존 Kotlin 녹음·Room·WorkManager와 직접 연결 |
| 오프라인 조건 | 런타임·모델 캐시 보존 및 브라우저 기능별 검증 필요 | 모델을 앱 내부 파일로 설치한 뒤 로컬 실행 |
| 현재 결정 | 별도 검토 대상으로 유지. 호환성·속도 실험 미실시 | 우선 구현 대상. 실제 Galaxy 성능 검증은 별도 필요 |

Transformers.js의 브라우저 지원을 Android 네이티브 지원이나 Galaxy 성능 검증으로 간주하지 않습니다.

## 엔진과 모델

- whisper.cpp v1.7.6. 소스 압축 SHA-256을 CMake에 고정합니다.
- 대상 ABI: `arm64-v8a` (Galaxy S23 Ultra). x86 에뮬레이터용 빌드는 제공하지 않습니다.
- CPU 4개 스레드, 한국어 전사, 로컬 M4A를 PCM/16kHz/mono로 변환해 JNI에 전달합니다.
- 초기 지원: 2분 이하 음성 메모. 더 긴 원본은 자르거나 삭제하지 않고 변환 실패로 안내합니다.
- 초기 리샘플러는 선형 보간 구현이며 실제 한국어 인식 품질은 기기에서 비교해야 합니다.

| 모델 | 실제 파일 크기 | 용도 | Galaxy 측정 |
| --- | ---: | --- | --- |
| base 다국어 | 147,951,465 bytes | 기본 시작 모델 | 미실시 |
| small Q5_1 다국어 | 190,085,487 bytes | 정확도·속도 비교 | 미실시 |
| large-v3-turbo Q5_0 | 574,041,195 bytes | 호환성·메모리 실험 | 미실시 |

모델 저장소 revision은 `5359861c739e955e79d9a303bcbc70fb988958b1`로 고정하고 파일 크기와 SHA-256을 확인합니다. 영문 전용 `.en` 모델을 한국어 기본값으로 선택하지 않습니다.

여유 메모리 기준은 base 600MB, small 1.2GB, turbo 3GB로 보수적으로 설정한 사전 검사이며 실제 사용량 측정 결과가 아닙니다. 모델 파일 크기도 실행 메모리와 다릅니다. turbo의 GGML 모델 존재는 Galaxy에서의 속도·안정성 증명이 아닙니다.

## 사용 절차

1. 앱의 음성인식 설정에서 base를 선택하고 저장합니다.
2. 선택 모델 다운로드를 누르고 파일 크기를 확인합니다. Wi-Fi 사용을 권장합니다.
3. 설치 상태를 확인합니다. 다운로드 실패 시 다시 누릅니다. 모델 다운로드만 인터넷을 사용합니다.
4. 녹음을 저장하고 메모 상세에서 기기 내 무료 음성 변환 / 재시도를 누릅니다.
5. 작업 상태 확인에서 완료를 확인한 뒤 목록으로 나갔다가 상세를 다시 열면 전사를 볼 수 있습니다.
6. 원하면 새 녹음 자동 로컬 변환을 켭니다. 기본은 꺼져 있습니다.
7. 실패하면 원본을 백업하고 모델·저장공간·여유 메모리를 확인한 뒤 다시 요청합니다. 기존 전사는 자동으로 덮어쓰지 않습니다.

## 보존과 네트워크

- Room 스키마의 기존 전사·처리 상태 필드를 사용합니다. 유료 전환 기능은 없습니다.
- 음성 변환 워커에는 HTTP 클라이언트와 네트워크 연결 조건이 없습니다.
- 네트워크 권한은 고정된 공개 모델 URL의 GET 다운로드와 다운로드 연결 확인에 필요합니다.
- 다운로드는 임시 파일에 기록하고 검증 후 설치합니다. 모델이 설치되면 음성 변환에 인터넷이 필요하지 않도록 구현합니다.
- 모델 다운로드 실패나 전사 실패 시 녹음 원본을 삭제하지 않습니다.
- 앱 삭제/앱 데이터 삭제 시 메모·녹음·모델이 삭제됩니다. 필요한 녹음은 ZIP으로 내보내세요.
- 중단·메모리 부족·강제 종료 시 네이티브 프로세스가 종료될 수 있습니다. 원본 보존과 실제 재시작 동작을 기기에서 검증해야 합니다.
- Gemini 프롬프트 복사는 텍스트를 클립보드에 넣는 별도 기능이며 녹음 파일을 전송하지 않습니다.

## Galaxy 실험 절차

1. USB 디버깅으로 연결하고 APK를 설치합니다.
2. 같은 한국어 10초/30초/60초 메모를 각 모델로 비교합니다. 기존 전사가 있으면 백업 후 전사 칸을 비우고 저장해야 다시 변환할 수 있습니다.
3. 모델별 전사 정확도, 총 처리 시간, 전후 PSS, 발열, 배터리 변화, UI 반응을 기록합니다.
4. 작업 상태의 전후 PSS는 최고 메모리 사용량이 아닙니다. 변환 중 `adb shell dumpsys meminfo com.kuiro.youtubemarker`를 반복 측정해 최대 관측값을 별도로 남깁니다.
5. 최초 모델 다운로드 뒤 비행기 모드를 켜고 Wi-Fi와 모바일 데이터가 모두 꺼졌는지 확인합니다. 새 녹음을 만들어 전사·검색·백업이 되는지 확인합니다.
6. 모델 누락/깨진 다운로드/메모리 부족/앱 강제 종료/재시도 후 원본 파일과 Room 메모가 유지되는지 확인합니다.
7. turbo가 느리거나 불안정하면 small 또는 base로 돌아갑니다. 유료 API로 전환하지 않습니다.

실기기 측정 전에는 오프라인 실동작·성능 검증 완료로 표시하지 않습니다.

Galaxy 연결과 설치는 `scripts/install-device.ps1`, 측정값 기록은 `docs/DEVICE-SESSION.md`를 사용합니다.

## 현재 자동 검증 범위

- 소스 검색으로 Groq/OpenAI 엔드포인트, Bearer 인증, API 키 입력·저장 코드가 없는지 확인합니다.
- `assembleDebug`, `lintDebug`, `testDebugUnitTest`를 실행합니다.
- APK에 `libyvm_whisper.so` ARM64 네이티브 라이브러리가 포함됐는지 확인합니다.
- APK에 `ggml-*.bin` 모델 파일이 포함되지 않았는지 확인합니다. 모델은 사용자가 별도로 다운로드합니다.
- `PcmResamplerTest`는 44.1kHz→16kHz 샘플 수, 16kHz 보존, 업샘플 경계, 지원하지 않는 샘플레이트를 확인합니다.

이 검사는 기기 마이크·스피커, 실제 한국어 정확도, 모델 로딩 성공, 최대 메모리 사용량을 대신하지 않습니다.
