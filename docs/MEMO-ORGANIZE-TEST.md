# 메모 편집·정리·백업

## 사용

1. 메모 목록에서 항목을 누르면 상세 화면이 열립니다.
2. 제목·영상 URL·시점·사용자 메모 전사·태그·카테고리를 수정하고 변경 내용 저장을 누릅니다.
3. 사용할 권한이 있는 자막에서 필요한 문장을 직접 선택·복사해 선택 자막 원문 칸에 붙여넣습니다. 자동 자막 수집이나 구간 추출은 구현하지 않았습니다.
4. Gemini용 프롬프트 복사를 누르면 현재 입력으로 프롬프트를 만듭니다. 저장하지 않은 입력도 포함되며, 앱이 Gemini로 자동 전송하지 않습니다.
5. 사용자가 Gemini에 붙여넣어 실행한 결과를 AI 요약 결과 칸에 붙여넣고 저장할 수 있습니다. 해당 외부 서비스 사용 조건과 비용은 사용자가 선택한 서비스에 따릅니다.
6. 원본 보존이 필요하면 저장된 메모 + 녹음 ZIP 백업을 누르고 시스템 파일 선택 창에서 위치를 고릅니다. ZIP에는 저장된 메모만 들어가므로 편집 내용을 먼저 저장하세요.
7. ZIP을 풀면 `note.json`과 `audio/<메모 ID>.m4a`를 확인할 수 있습니다. 녹음이 없거나 비어 있으면 JSON에만 그 사실을 표시합니다. 앱으로 ZIP을 다시 가져오는 기능은 아직 없습니다.
8. 삭제는 메모와 녹음을 영구 삭제하며 별도 확인을 거칩니다. 녹음 중인 메모는 수정·삭제·백업할 수 없습니다.
9. 목록의 처리 대기만 보기로 변환 대기·실패·중단 항목을 확인합니다. 실제 변환 실행·재시도 워커는 아직 연결하지 않았습니다.

## 데이터와 개인정보

- 현재 전사·선택 자막·요약은 수동 입력입니다. Whisper 또는 AI가 실제로 생성한 결과로 표시하지 않습니다.
- 프롬프트는 사용자 메모와 영상 자막을 서로 다른 출처로 구분합니다. 자막이 없으면 영상 원문을 확인할 수 없다고 명시합니다.
- 복사한 내용은 시스템 클립보드로 전달됩니다. Gemini에 붙여넣어 전송하는 것은 사용자가 결정합니다.
- ZIP 저장 위치로 클라우드 제공자를 선택하면 해당 제공자의 동기화 방식이 적용될 수 있습니다. 앱은 별도 업로드 API를 호출하지 않습니다.
- ZIP은 암호화하지 않습니다. 민감한 녹음은 사용자가 관리하는 안전한 위치에 보관하세요.
- 삭제 시 DB 삭제가 성공한 뒤 음성 파일을 제거합니다. 파일 제거가 실패하면 오류를 안내하며 파일이 내부 저장소에 남을 수 있습니다.
- 다른 창이나 녹음 서비스가 수정한 메모는 오래된 편집 화면에서 덮어쓰지 않도록 수정 시각을 대조합니다.

## 검증

호스트 자동 검사: APK 빌드·Room SQL 생성·Lint·단위 테스트.
단위 테스트 6개: 마이크 소유권 1개, 프롬프트 출처/누락 정보 2개, ZIP 원본 보존/누락 파일/경로 제한 3개.

Galaxy에서 확인할 항목:

- 저장 후 재실행해 편집 내용 유지 및 태그·자막·요약 검색 확인
- 편집 중 회전 후 입력 유지, 뒤로가기 시 저장하지 않은 변경 확인
- Gemini 프롬프트 붙여넣기로 한글·줄바꿈·출처 구분 확인
- 시스템 저장 창 취소·회전·저장공간 부족 시 원본 유지 확인
- 실제 녹음 ZIP 추출 후 재생과 메타데이터 확인
- 삭제 취소/확정 및 녹음 중 수정 차단 확인

이 기기 검증은 아직 실행하지 않았습니다.
