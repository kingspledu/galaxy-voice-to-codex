# 개인정보 처리 안내 초안

YouTube Voice Marker는 음성 메모와 메모 정보를 기본적으로 Android 기기 내부에 저장합니다.

- 녹음 파일은 앱 내부 `noBackupFilesDir/recordings`에 저장합니다.
- Room 데이터베이스에는 영상 URL, 수동 시점, 녹음 경로, 전사 상태와 사용자가 입력한 자막·요약이 저장됩니다.
- 무료 whisper.cpp 엔진은 다운로드한 모델을 기기 안에서 실행합니다. 음성 파일을 외부 음성인식 서버로 전송하지 않습니다.
- 모델 파일은 사용자가 선택한 공개 저장소에서 최초 다운로드하며, SHA-256을 확인한 뒤 설치합니다.
- Gemini용 프롬프트는 클립보드에 복사할 뿐 자동 전송하지 않습니다. 사용자가 다른 앱에 붙여넣을 때 해당 앱의 정책이 적용됩니다.
- ZIP 백업은 사용자가 선택한 저장 위치에 기록됩니다. 앱은 백업 파일을 암호화하지 않습니다.
- 앱 삭제 또는 앱 데이터 삭제 시 내부 녹음·메모·모델이 삭제될 수 있습니다.
- YouTube 공식 앱의 현재 재생 위치나 자막을 자동으로 읽지 않습니다. 공유 URL과 사용자가 입력·선택한 정보만 저장합니다.

이 문서는 개발 단계 초안이며, 공개 배포 전 실제 앱 동작·법적 검토·연락처를 반영해 갱신해야 합니다.
