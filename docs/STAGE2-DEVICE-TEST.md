# 2단계 Galaxy 테스트 절차

이 단계는 앱 내부 녹음입니다. YouTube 위 플로팅 녹음은 아직 구현되지 않았습니다.

1. APK를 설치하고 앱을 엽니다. 녹음 시작 → 마이크 허용 → 5초 이상 말하기 → 종료하고 저장을 누릅니다.
2. 목록에서 메모를 누르고 녹음 듣기로 음성을 확인합니다.
3. 앱 종료 후 다시 열어 메모가 유지되는지 확인합니다.
4. 제목으로 검색하고 검색어를 지웠을 때 전체 목록이 복원되는지 확인합니다.
5. YouTube 공유 → 앱 선택 → URL 확인 → 영상 시점에 `12:34`를 입력해 녹음합니다. 영상 열기가 해당 시점 링크를 여는지 확인합니다. 자동 시점 수집은 없습니다.
6. `12:99` 또는 다른 사이트 주소 입력 시 녹음 시작이 차단되는지 확인합니다.
7. 마이크 권한 거부 시 충돌 없이 안내하는지 확인합니다.
8. 녹음 도중 홈 버튼, 화면 회전, 화면 잠금을 각각 시험해 자동 종료된 파일을 다시 들을 수 있는지 확인합니다.
9. 녹음 도중 강제 종료 후 다시 열면 중단됨으로 표시되는지 확인합니다. 비정상 종료된 M4A는 재생되지 않을 수 있습니다. 파일은 삭제하지 않습니다.
10. 빠르게 시작·종료하거나 다른 앱이 마이크를 사용 중인 상황에서 오류 표시와 파일 보존을 확인합니다.

## 저장과 개인정보

- Room DB는 앱 내부 저장소, 음성 파일은 `noBackupFilesDir/recordings`에 저장합니다.
- 녹음 전에 DB 레코드를 만들고 녹음 종료 후 처리 상태를 갱신합니다.
- DB 접근은 단일 백그라운드 실행기에서 순서대로 처리합니다.
- 변환 API 및 업로드는 연결하지 않았으며 인터넷 권한도 없습니다.
- 앱 삭제 또는 앱 데이터 삭제 시 내부 메모와 녹음이 삭제됩니다. 내보내기는 아직 없습니다.
- 강제 종료·전원 차단 때 파일의 존재와 재생 가능성은 다릅니다. 중단 파일 복구 가능 여부는 실기기 검증이 필요합니다.
- 별도 처리 대기 화면, 메모 편집·삭제, 플로팅 서비스, Whisper는 후속 단계입니다.

참고: [MediaRecorder](https://developer.android.com/media/platform/mediarecorder), [Room](https://developer.android.com/training/data-storage/room).
